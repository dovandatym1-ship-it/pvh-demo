## 2. Ràng buộc nghiệp vụ sơ bộ
Cơ sở–nhóm/lớp; đối tượng–chính sách–kỳ; thống kê theo địa bàn và nguồn, không xây SIS toàn trường.

## 3. Breakdown bắt buộc cho TỪNG feature (lặp lại với từng ID phía trên)
- [ ] OP-01 Actor, owner, quyền pháp lý, mục đích, scope xã/tenant.
- [ ] OP-02 Create: form, trường, default, nguồn, validation, kiểm trùng, success/error, audit.
- [ ] OP-03 Read: list/detail, bộ lọc, sort, paging, search, phân quyền field/record, empty state.
- [ ] OP-04 Update: trường sửa được, optimistic locking, trạng thái khóa, lịch sử thay đổi.
- [ ] OP-05 Delete: soft/hard/archive, xác nhận, kiểm FK, hậu quả liên kết, phục hồi nếu cho phép.
- [ ] OP-06 Import/export: loại tệp, mapping, giới hạn, lỗi theo dòng, quyền, mẫu in nếu cần.
- [ ] OP-07 Workflow (nếu có): state, transition, guard, actor, deadline, rollback/cancel.
- [ ] OP-08 Exception: thiếu dữ liệu, trùng, hết quyền, sai tenant, nguồn ngoài lỗi, concurrent edit.
- [ ] OP-09 UI: list, form, detail, validation feedback, accessibility, responsive.
- [ ] OP-10 API/data: endpoint, DTO, idempotency, transaction, unique, FK, index, retention.
- [ ] OP-11 Tests: positive/negative, boundary, permission, cross-tenant, export, audit.
- [ ] OP-12 RTM: requirement ID → screen → entity → rule → test → evidence → reviewer.
